# caderno-notebooklm
Criação de um caderno temático no NotebookLM sobre déficit calórico.

Tive como objetivo pesquisar sobre déficit calórico e como ele afeta o nosso corpo, assim como para saber quais são os alimentos recomendados para manter a saciedade com poucas calorias.
